# dsh-feishu 功能规格

## 11. 云盘模块（drive）详细规格

### 11.1 验证连接

**Tool**: `feishu_verify_connection`
**入参**: `appId: string`, `appSecret: string`
**处理**:
1. 调用 `POST /auth/v3/tenant_access_token/internal`
2. 验证返回 `code == 0`
3. 获取 token 成功后，调用 `GET /drive/v1/files?page_size=1` 确认权限
**出参**: `{ success: boolean, message: string, quota?: { used: number, total: number } }`
**权限 scope**: `auth:app_access_token` + `drive:file`

### 11.2 上传文件

**Tool**: `feishu_upload_file`
**入参**: `localPath: string`, `remotePath?: string`（默认 `/DSH-Backup/`)
**处理**:
1. 读取本地文件（Node.js `fs.readFile`）
2. 检查文件大小 ≤ 20MB
3. 调用 `POST /drive/v1/upload_all`（`file` 二进制 + `file_name` + `parent_type=explorer`）
4. 返回 `file_token`
**注意**: `> 20MB` 的文件返回错误，引导用户使用 dsh-config-manager 分卷
**出参**: `{ success: boolean, fileToken: string, fileName: string, size: number }`
**权限 scope**: `drive:file`

### 11.3 下载文件

**Tool**: `feishu_download_file`
**入参**: `fileToken: string`, `savePath: string`
**处理**:
1. 调用 `GET /drive/v1/files/{file_token}/download`
2. 接收二进制响应流
3. 写入 `savePath`
**出参**: `{ success: boolean, path: string, size: number }`
**权限 scope**: `drive:file`

### 11.4 列出文件

**Tool**: `feishu_list_files`
**入参**: `folderToken?: string`, `pageSize?: number`（默认 50）
**处理**:
1. 调用 `GET /drive/v1/files?folder_token={}&page_size={}`
2. 解析文件列表
**出参**: `{ files: Array<{ token, name, size, created_at, updated_at, type }> }`
**权限 scope**: `drive:file`

### 11.5 删除文件

**Tool**: `feishu_delete_file`
**入参**: `fileToken: string`
**处理**:
1. 调用 `DELETE /drive/v1/files/{file_token}`
**出参**: `{ success: boolean }`
**权限 scope**: `drive:file`

### 11.6 获取云盘容量

**Tool**: `feishu_get_quota`
**入参**: 无
**处理**:
1. 调用 `GET /drive/v1/files?page_size=1` 从响应头提取 `X-Drive-Quota`
**出参**: `{ used: number, total: number }`（单位：字节）

## 12. 云文档模块（docx）详细规格

### 12.1 创建文档

**Tool**: `feishu_create_doc`
**入参**: `title: string`
**处理**:
1. 调用 `POST /docx/v1/documents`（body: `{ title }`）
2. 返回 `document_id`
**出参**: `{ success: boolean, documentId: string, title: string }`
**权限 scope**: `docx:document`

### 12.2 写入文本块

**Tool**: `feishu_write_block`
**入参**: `documentId: string`, `text: string`, `index?: number`（插入位置，默认末尾）
**处理**:
1. 调用 `POST /docx/v1/documents/{document_id}/blocks/{block_id}/children`
2. 构建文本 block: `{ block_type: 2, text: { elements: [{ text_run: { content } }] } }`
**注意**: 每次写入是一个 HTTP 请求；批量写入需循环
**出参**: `{ success: boolean, blockId: string }`
**权限 scope**: `docx:document`

### 12.3 读取文档

**Tool**: `feishu_read_doc`
**入参**: `documentId: string`
**处理**:
1. 调用 `GET /docx/v1/documents/{document_id}/blocks?page_size=500`
2. 递归获取所有 block（处理 `has_more`）
3. 拼接文本内容
**出参**: `{ success: boolean, title: string, blocks: Block[] }`
**权限 scope**: `docx:document`

### 12.4 列举文档

**Tool**: `feishu_list_docs`
**入参**: `folderToken?: string`
**处理**:
1. 调用 `GET /drive/v1/files?folder_token={}&order_by=EditedTime&direction=DESC`
2. 过滤 `type == "docx"` 的文件
**出参**: `{ docs: Array<{ token, name, edited_at }> }`
**权限 scope**: `docx:document` + `drive:file`

### 12.5 删除文档

**Tool**: `feishu_delete_doc`
**入参**: `documentId: string`
**处理**:
1. 调用 `DELETE /drive/v1/files/{file_token}`（用 documentId 作为 file_token）
**出参**: `{ success: boolean }`
**权限 scope**: `docx:document`

## 13. 多维表格模块（bitable）详细规格

### 13.1 创建多维表格

**Tool**: `feishu_create_bitable`
**入参**: `name: string`
**处理**:
1. 调用 `POST /bitable/v1/apps`
2. 返回 `app_token`
**出参**: `{ success: boolean, appToken: string, name: string }`
**权限 scope**: `bitable:app`

### 13.2 列举多维表格

**Tool**: `feishu_list_bitables`
**入参**: 无
**处理**:
1. 调用 `GET /bitable/v1/apps`
**出参**: `{ apps: Array<{ appToken, name }> }`
**权限 scope**: `bitable:app`

### 13.3 获取表结构

**Tool**: `feishu_get_bitable_fields`
**入参**: `appToken: string`
**处理**:
1. 调用 `GET /bitable/v1/apps/{app_token}/tables`
2. 对每个 table 调用 `GET /bitable/v1/apps/{app_token}/tables/{table_id}/fields`
**出参**: `{ tables: Array<{ tableId, name, fields: Field[] }> }`
**权限 scope**: `bitable:app`

### 13.4 新增记录

**Tool**: `feishu_insert_bitable_record`
**入参**: `appToken: string`, `tableId: string`, `fields: Record<string, any>`
**处理**:
1. 调用 `POST /bitable/v1/apps/{app_token}/tables/{table_id}/records`
2. body: `{ fields }`
**出参**: `{ success: boolean, recordId: string }`
**权限 scope**: `bitable:app`

### 13.5 查询记录

**Tool**: `feishu_query_bitable_records`
**入参**: `appToken: string`, `tableId: string`, `filter?: string`, `pageSize?: number`
**处理**:
1. 调用 `GET /bitable/v1/apps/{app_token}/tables/{table_id}/records?page_size={}`
**出参**: `{ records: Record[], total: number }`
**权限 scope**: `bitable:app`

### 13.6 删除记录

**Tool**: `feishu_delete_bitable_record`
**入参**: `appToken: string`, `tableId: string`, `recordId: string`
**处理**:
1. 调用 `DELETE /bitable/v1/apps/{app_token}/tables/{table_id}/records/{record_id}`
**出参**: `{ success: boolean }`
**权限 scope**: `bitable:app`

### 14.2 错误提示对照表

| 错误码 | 含义 | 用户操作 |
|--------|------|---------|
| `99991401` | App Secret 错误 | 检查 App Secret 是否复制正确 |
| `99991664` | 权限未开通 | 引导去权限管理页开通 |
| `99991403` | token 过期 | SDK 自动刷新，无需操作 |
| `230013` | 文件超限（>20MB） | 提示用户文件过大，建议压缩后上传 |
| `230001` | 频率超限（>5 QPS） | 自动重试，带退避 |

## 15. 配置 Schema

```typescript
export interface FeishuConfig {
  // 连接凭证
  appId: string
  appSecret: string  // role('secret')

  // 云盘设置
  driveFolderToken?: string  // 备份上传的文件夹 token，默认根目录

  // 云文档设置
  docxFolderToken?: string   // 文档创建目录

  // 多维表格设置
  bitableFolderToken?: string

  // 高级
  uploadTimeout?: number      // 上传超时（ms），默认 60000
  maxFileSize?: number       // 最大文件MB，默认 20
  locale?: 'zh-CN' | 'en'
}

export const Config: Schema<FeishuConfig> = Schema.object({
  appId:     Schema.string(),
  appSecret: Schema.string().role('secret'),
  driveFolderToken: Schema.string().optional(),
  docxFolderToken:  Schema.string().optional(),
  bitableFolderToken: Schema.string().optional(),
  uploadTimeout: Schema.number().min(5000).max(300000).default(60000),
  maxFileSize:  Schema.number().min(1).max(20).default(20),
  locale:      Schema.enum(['zh-CN', 'en']).default('zh-CN'),
})
```

## 16. 错误处理策略

| 错误类型 | 处理策略 |
|----------|---------|
| 网络超时 | 重试 3 次，指数退避（1s → 2s → 4s）|
| 权限不足（403）| 提示用户检查权限，禁用相关功能按钮 |
| 文件超限（230013）| 明确告知文件大小限制，引导压缩 |
| Token 失效 | SDK 自动刷新 token |
| QPS 限制（230001）| 队列 + 延迟，告知用户等待 |
| 应用不存在 | 检查 App ID 是否正确 |

---

## 17. 性能注意事项

- SDK 调用使用 HTTP keep-alive，复用连接
- 列表文件使用分页（page_size=50），不一次加载全部
- 上传/下载使用流式处理，避免大文件撑爆内存
- SDK 客户端单例复用，不每次调用都 new
