# dsh-feishu — 飞书全能力 DSH 插件

## 1. 项目概述

### 1.1 项目名称

- **插件名**：`dsh-feishu`
- **npm 包名**：`dsh-feishu`（待发布时确认）
- **GitHub 仓库**：`dsh-feishu`

### 1.2 一句话描述

让 DeepSeek Harness 直接读写飞书云盘、云文档和多维表格，实现配置备份、任务协作和跨设备同步的完整闭环。

### 1.3 核心价值

- 用飞书 100G 免费云盘作为 DSH 配置备份网盘，换设备不丢配置
- 把 DSH 会话记录、备份清单写入飞书云文档，可分享、可协作
- 用多维表格管理 DSH 插件清单、备份记录、任务列表

### 1.4 已知约束（调查结论，勿违背）

| 约束 | 说明 |
|------|------|
| 飞书无 WebDAV | 云盘不支持 WebDAV，无法直连 dsh-webdav |
| 20MB 文件限制 | `upload_all` 接口每次上传 ≤ 20MB，超过需分卷 |
| 5 QPS 限制 | 云盘 API 调用频率上限 5 次/秒 |
| 无一键创建应用 | 飞书开放平台无公开 API，必须在控制台手动创建应用 |
| 权限需手动审批 | 企业版需管理员审批，个人版自批 |
| App Secret 需安全存储 | 必须用 `role('secret')` + `ctx.credentials`，绝不落盘 |

## 2. 功能范围

### 2.1 v1 阶段（MVP，最小可行版）

**云盘（drive）**
- 验证连接（获取 tenant_access_token）
- 上传文件（≤ 20MB）
- 下载文件
- 列出文件/文件夹
- 删除文件
- 显示云盘容量和使用情况

**云文档（docx）**
- 创建空白文档
- 写入文本块（逐 block 写入）
- 读取文档内容
- 获取文档列表
- 删除文档

**多维表格（bitable）**
- 创建多维表格
- 新增/查询/删除记录
- 获取表结构
- 列举多维表格列表

### 2.2 v2 阶段（完善）

- 分卷上传（处理 > 20MB 的备份文件）
- 云文档富文本写入（标题/列表/代码块）
- 多维表格批量操作
- 定时备份触发器（调用 dsh-config-manager 导出后自动上传）
- 从飞书文档恢复配置（读取文档 → 解析 → 导入）

### 2.3 不做的功能（调查后排除）

- IM 消息（已有 dsh-lark-channel 做 IM Bot）
- 日历/通讯录（非备份场景核心）
- 一键创建飞书应用（飞书平台限制，必须手动）
- WebDAV 模拟层（复杂度太高，收益低）

## 3. 技术选型

### 3.1 核心依赖

| 依赖 | 选择 | 理由 |
|------|------|------|
| 飞书 SDK | `@larksuiteoapi/node-sdk` | 官方维护，支持 TypeScript，处理了 token 刷新和文件流 |
| DSH 框架 | Cordis 插件架构 | 官方标准，settings card + host tool 双面设计 |
| 构建工具 | `tsdown` | DSH 官方插件构建工具，与官方模板一致 |
| 凭证存储 | DSH `ctx.credentials` | 官方安全存储，不进日志/配置/响应 |
| UI 框架 | DSH 官方 `dsh-client-ui-settings-plugins` | 官方 settings card 方案 |

## 4. 飞书应用权限设计

### 4.1 v1 需要申请的权限

| 权限名称 | scope | 用途 | 申请方式 |
|---------|-------|------|---------|
| 查看、评论、编辑云盘文件 | `drive:file` | 上传/下载/列表/删除文件 | 个人版：自批；企业版：管理员审批 |
| 获取 access_token | `auth:app_access_token` | 获取调用令牌 | 同上 |

### 4.2 v2 会增加的权限

| 权限名称 | scope | 用途 |
|---------|-------|------|
| 云文档读写 | `docx:document` | 创建/写入/读取云文档 |
| 多维表格数据 | `bitable:app` | 多维表格记录增删改查 |

### 4.3 权限引导流程

插件设置页提供图文引导：

```
第1步：创建飞书应用
  → 打开 https://open.feishu.cn/app
  → 点击「创建自建应用」
  → 填写应用名称（建议：DSH 备份助手）

第2步：配置权限
  → 进入应用 → 权限管理
  → 搜索并开通「云盘文件」权限（drive:file）
  → 如需云文档：搜索并开通「云文档」权限

第3步：获取凭证
  → 进入「凭证与基础信息」页
  → 复制 App ID 和 App Secret

第4步：粘贴到下方
  → 填入 App ID + App Secret
  → 点击「验证连接」

企业版用户注意：
  → 权限需管理员在「应用管理」中审批
  → 审批通过后重新验证连接
```

## 5. 安全设计

### 5.1 App Secret 安全存储

```typescript
// Config schema — App Secret 绝不走配置文件明文
export const Config: Schema<Config> = Schema.object({
  appId:     Schema.string(),
  appSecret: Schema.string().role('secret'), // ← 不进日志/响应
})

// 运行时读取 — 从 DSH 凭证系统获取
const secret = await ctx.credentials.get('dsh-feishu.appSecret')
```

### 5.2 Token 处理

- `tenant_access_token` 有效期 2 小时，SDK 自动刷新
- 不将 token 暴露在任何日志或响应中
- 连接断开后自动清除内存中的 token

### 5.3 开源透明度

- 插件代码完整开源（发布到 GitHub）
- 用户可自行审计是否有后门或凭证泄露
- 不使用任何第三方追踪库
