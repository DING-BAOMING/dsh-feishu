## 45. 发布渠道详解

### 45.1 GitHub Releases（核心）

- **仓库**：`https://github.com/<username>/dsh-feishu`
- **协议**：MIT License
- **内容**：每个 Release 包含：
  - 预编译 `.tgz` 包（pnpm pack 产物）
  - CHANGELOG.md
  - Source code (auto-generated by GitHub)
- **Tag 约定**：`v<version>`（如 `v1.0.0-alpha.1`）

```bash
# 发布流程
git tag v1.0.0-alpha.1
git push origin v1.0.0-alpha.1
# GitHub Actions 自动构建 + 创建 Release
```

### 45.2 npm（安装源）

- **包名**：`dsh-feishu`
- **作用域**：无作用域（public）
- **安装命令**：
  ```bash
  dsh plugin add dsh-feishu      # 最新稳定版
  dsh plugin add dsh-feishu@alpha # alpha 测试版
  ```

### 45.3 dsh.so 插件市场

- **URL**：`https://dsh.so/plugin/dsh-feishu`
- **提交方式**：在 dsh.so 提交页面填入 GitHub 仓库地址
- **审核**：自动扫描 + 人工抽查
- **须知**：
  - 包名必须与 npm 一致
  - README 第一行必须是描述
  - 必须有 MIT/Apache 2.0 协议

### 45.4 DSH 中文社区（dshx.dev）

- **URL**：`https://dshx.dev/`
- **发布形式**：中文帖（插件介绍 + 安装教程）
- **内容**：
  - 插件功能截图
  - 安装命令
  - 飞书应用创建引导（图文）
  - 常见问题 FAQ

### 45.5 Gitee / OSCHINA（国内镜像）

- **目的**：国内用户访问 GitHub 慢
- **同步方式**：GitHub → Gitee 自动同步（用 GitHub Actions）
- **URL**：待创建

## 46. 发布检查清单

发布前逐项确认：

### 通用
- [ ] 所有 TypeScript 类型完整，无 `any`
- [ ] ESLint `pnpm lint` 通过
- [ ] `README.md` 包含：安装命令、功能列表、截图、FAQ
- [ ] `LICENSE` 文件存在（MIT）
- [ ] `CHANGELOG.md` 记录本次变更

### 安全
- [ ] `appSecret` 有 `role('secret')`
- [ ] 无硬编码凭证
- [ ] `package.json` `files` 字段不包含 `src`
- [ ] SDK 日志级别不是 `debug`

### npm
- [ ] `npm whoami` 确认已登录
- [ ] `pnpm publish --dry-run` 预览正常
- [ ] 发布成功后 `npm view dsh-feishu` 可查到

### dsh.so
- [ ] GitHub 仓库是 public
- [ ] README 包含安装命令
- [ ] 提交审核后等待确认（通常 1~3 工作日）

## 47. 社区运营计划

### 47.1 首发宣传

| 时间 | 渠道 | 内容 |
|------|------|------|
| 发布当天 | GitHub Release | Release Note（英文） |
| 发布当天 | dshx.dev 帖子 | 中文介绍 + 安装教程 |


## 48. 维护计划

### 48.1 Bug 处理

| 类型 | 处理时间 | 版本 |
|------|---------|------|
| 崩溃/数据丢失 | 24 小时内修复 | 紧急 patch |
| 功能不工作（非核心） | 1 周内修复 | 下一版本 |
| 文档错误 | 发现即修复 | 文档更新 |

### 48.2 版本维护窗口

- **活跃维护**：发布后 3 个月内，所有问题优先处理
- **低维护**：3 个月后，重要问题仍修，minor feature 合并到下一版本
- **归档**：超过 1 年未更新的版本，在 README 标注"建议升级"

### 48.3 飞书 API 变更应对

- 订阅 [飞书开放平台更新日志](https://open.feishu.cn/changelog)
- API 不兼容变更时：检测并提示用户 + 文档说明 + 2 周内修复
