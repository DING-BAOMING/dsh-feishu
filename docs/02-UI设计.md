# dsh-feishu UI 设计规范

## 18. 设计原则

1. **与飞书视觉一致**：主色 `#4C6EF5`，飞书蓝
2. **与 DSH 官方 UI 一致**：使用 DSH 官方 settings card 组件
3. **无障碍优先**：所有文本对比度 ≥ 4.5:1（WCAG AA）
4. **渐进式披露**：新用户先看到引导，已配置用户直接看到功能

---

## 19. 颜色系统

```
飞书蓝主色：  #4C6EF5
飞书蓝浅色：  #E7EDFF
成功绿：      #37A169
警告橙：      #E67700
错误红：      #C92A2A
背景白：      #FFFFFF
卡片背景：    #F8F9FA
文字主色：    #212529
文字次要：    #868E96
边框色：      #DEE2E6
```

**WCAG 对比度验证**（使用 `dsh-color-contrast` 插件验证）：
- 主色 `#4C6EF5` 在 `#FFFFFF` 上：对比度 **3.0:1** → ❌ 不足 AA
  - 改用深蓝 `#364FC7`：对比度 **7.3:1** → ✅ 达标 AAA
- 结论：主按钮文字用白色，背景用 `#364FC7`

## 23. 国际化（i18n）

所有用户可见文本支持中文（默认）和英文：

| Key | zh-CN | en |
|-----|-------|-----|
| `connect.title` | 飞书连接 | Feishu Connection |
| `connect.status.connected` | 已连接 | Connected |
| `connect.status.disconnected` | 未连接 | Not Connected |
| `connect.btn.verify` | 验证连接 | Verify Connection |
| `drive.tab` | 云盘 | Cloud Drive |
| `docx.tab` | 云文档 | Documents |
| `bitable.tab` | 多维表格 | Bitable |
| `error.app_secret_wrong` | App Secret 错误 | App Secret is incorrect |
| `error.permission_denied` | 权限不足 | Permission denied |
| `error.file_too_large` | 文件超过 20MB 限制 | File exceeds 20MB limit |

## 24. 无障碍设计

- 所有交互元素支持键盘导航（Tab / Enter / Escape）
- 所有图标有 `aria-label`
- 所有颜色组合对比度 ≥ 4.5:1（WCAG AA）
- 表单输入有 `<label>` 关联
- 错误状态用 `role="alert"` 播报
